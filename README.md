# 🛒Supermercado

O Supermercado é uma aplicação que simula uma lista de compras, permitindo organizar os produtos que precisam ser comprados.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
